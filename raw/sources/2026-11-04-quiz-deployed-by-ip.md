# Публикация анкеты по IP-адресу

Пользователь попросил загрузить обновлённую HTML-анкету на сервер и открыть её по IP-адресу. В той же сессии он попросил убрать вводный текст: «Заповніть 13 простих питань. Це анкета для власника й команди сайту, а не квіз для покупців. У кожному полі є приклад відповіді.»

Ранее пользователь разрешил перенос Telegram-токена и chat ID на сервер при условии, что путь для хранения будет сначала согласован с ним.
