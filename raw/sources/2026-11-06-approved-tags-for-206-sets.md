# Утверждённый формат анализа и тегов для 206 наборов

Дата: 2026-11-06

Пользователь поручил разобрать все наборы раздела сайта «За потребами»: состав, назначение, вид спорта, дистанцию, цену и вес покупателя; разрешил добавлять другие полезные метрики. В уточнении пользователь одобрил структурированный формат с источником для каждой карточки, точной ценой в гривнах, весом покупателя только при наличии подтверждённых данных и явными пометками для неизвестных значений.

Для цен за исходную точку берётся снимок каталога от 2026-11-06. Если актуальная карточка показывает другое значение, фиксируется расхождение, а исходную цену не заменяют молча.

Правила маркировки: не выводить вес покупателя или точную дистанцию из предположений; отделять вес/размер товара от веса человека; общие упоминания клуба не считать назначением конкретного набора; заявления о здоровье передавать как описание сайта, не как подтверждённые медицинские эффекты.
