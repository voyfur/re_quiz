# Уточнение объёма первой версии квиза и переносимого каталога наборов

Дата: 2026-11-09.

## Решение по первой версии

- Первая версия покупательского квиза работает только с готовыми наборами категории сайта «За потребами» — текущая выборка составляет 206 наборов.
- По конкретным ответам покупателя квиз выбирает один или несколько готовых наборов из этой выборки.
- Результат должен вести на страницу рекомендованного набора на сайте. Покупательский интерфейс может быть отдельной страницей или всплывающим окном; форма показа ещё не выбрана.
- Отдельная рекомендация товаров и сборка новых наборов AI не входят в первую версию. Это отдельные будущие сценарии с самостоятельными требованиями и правилами.

## Архитектурное пожелание

Логику первой версии желательно устроить так, чтобы начать с локальных данных 206 наборов, а позже подключить каталог сайта или базу данных по артикулам/ID с небольшими изменениями. Способ получения данных для будущей интеграции не утверждён; прямое подключение к БД не является решением владельца.

Источник: уточнение пользователя в чате 2026-11-09.
